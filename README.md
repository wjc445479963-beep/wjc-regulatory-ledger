# 法规合规台账

这是“wjc 的韭菜花园”中的法规合规台账模块，当前为基于 React、Vinext 和 TypeScript 的纯静态网站项目。

## 当前功能

- 公开展示现行和即将实施的法规、标准及指导文件；
- 按法规类别筛选并分页浏览；
- 支持上传 `.xlsx`、`.csv` 和 `.tsv` 文件，在浏览器本地完成法规版本比对；
- 识别标准编号和无编号文件，并标记新增、现行、即将实施、需要替换和未匹配结果；
- 提供法规比对结果导出；
- 内置唯一的最新法规主库，保留必要的历史替代关系；
- 不将用户上传的文控清单上传到服务器。
- 不依赖运行时登录或数据库；法规主库随 GitHub 源代码一起更新。
- 可通过 GitHub Pages 自动发布到免费的 `github.io` 地址。

## 运行要求

- Node.js `>=22.13.0`；
- Linux 环境；
- 依赖安装完成后运行 `npm run build` 构建；
- 运行 `npm run start` 启动本地构建后的应用（仅用于本地预览）。

## 常用命令

```bash
npm run install:ci
npm run build
npm test
npm run lint
```

## 主要目录

- `app/`：页面、法规主库和比对逻辑；
- `public/`：模板、图片和下载资源；
- `components/ui/`：界面组件；
- `tests/`：构建输出和基础界面测试；
- `db/`：为后续管理员、主库更新和日志功能预留的数据层；
- `scripts/`：安装和构建辅助脚本。

## GitHub Pages 发布

仓库中的 `.github/workflows/deploy-pages.yml` 会在 `main` 分支有新提交时自动构建并发布静态网站。首次启用后，项目网站地址为：

`https://wjc445479963-beep.github.io/wjc-regulatory-ledger/`

GitHub Pages 地址用于测试和公开访问，不需要额外购买域名。以后如果需要使用自己的域名，只需将现有域名绑定到发布平台，不必重新购买域名。

## 阿里云迁移说明

当前版本直接以 GitHub 源文件作为法规主库，比对文件和公开导出均在浏览器本地处理。将来如果需要在线账号、多人协作、数据库写入、自动扫描或审计日志，再单独增加服务器能力。

域名备案通过前，不要将正式域名解析到阿里云服务器，也不要对公网开放网站服务。

## 数据原则

- 只保留一个最新法规主库；
- 用户上传文件只作为比对对象；
- 旧清单不作为独立法规库；
- 历史版本只用于识别需要替换的文件；
- 无编号法规与有编号法规统一纳入同一主库。

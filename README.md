# 法规合规台账

这是“wjc 的韭菜花园”中的法规合规台账模块，当前为基于 React、Vinext 和 TypeScript 的网站项目。

## 当前功能

- 公开展示现行和即将实施的法规、标准及指导文件；
- 按法规类别筛选并分页浏览；
- 支持上传 `.xlsx`、`.csv` 和 `.tsv` 文件，在浏览器本地完成法规版本比对；
- 识别标准编号和无编号文件，并标记新增、现行、即将实施、需要替换和未匹配结果；
- 提供法规比对结果导出；
- 内置唯一的最新法规主库，保留必要的历史替代关系；
- 不将用户上传的文控清单上传到服务器。

## 运行要求

- Node.js `>=22.13.0`；
- Linux 环境；
- 依赖安装完成后运行 `npm run build` 构建；
- 运行 `npm run start` 启动构建后的应用。

## 常用命令

```bash
npm run install:ci
npm run build
npm test
npm run lint
```

## 主要目录

- `app/`：页面、法规主库和比对逻辑；
- `public/`：模板、图片和下载资源；
- `components/ui/`：界面组件；
- `tests/`：构建输出和基础界面测试；
- `db/`：为后续管理员、主库更新和日志功能预留的数据层；
- `scripts/`：安装和构建辅助脚本。

## 阿里云迁移说明

当前临时版本可以直接构建，但主库数据仍以内置文件为主，比对文件在浏览器本地处理。迁移到阿里云时，正式版本应继续使用这份源代码，并在服务器侧补充数据库、管理员更新后台、官方来源扫描、更新日志、备份和回滚机制。

域名备案通过前，不要将正式域名解析到阿里云服务器，也不要对公网开放网站服务。

## 数据原则

- 只保留一个最新法规主库；
- 用户上传文件只作为比对对象；
- 旧清单不作为独立法规库；
- 历史版本只用于识别需要替换的文件；
- 无编号法规与有编号法规统一纳入同一主库。

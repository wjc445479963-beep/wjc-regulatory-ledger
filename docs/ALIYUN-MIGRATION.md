# 阿里云迁移基线

## 当前阶段

当前项目仍然是 Sites 版本，法规主库主要存放在 `app/regulations-data.ts`，上传文件只在用户浏览器内解析和比对。阿里云迁移时，应先保证现有前端功能与主库数据完整，再逐步接入服务端能力。

## 正式迁移需要补充的服务端能力

1. 使用数据库保存主库记录、版本关系、官方来源和更新时间；
2. 使用管理员账号保护新增、替换、状态更新和来源维护操作；
3. 增加官方来源扫描任务，记录每次扫描结果；
4. 对高置信度的新版本自动更新，对有歧义的结果进入管理员确认；
5. 保留更新日志、数据库备份和回滚版本；
6. 公开页面只展示现行和即将实施记录，历史记录用于版本比对。

## 部署前检查

- Node.js 版本满足项目要求；
- `npm run build` 成功；
- `npm test` 成功；
- 不提交 `.env`、密钥、密码或服务器凭证；
- 备案通过后再进行正式域名解析和 HTTPS 配置。
